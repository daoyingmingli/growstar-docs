O StarMint App é um aplicativo iOS voltado para pais, projetado para ajudá-los a registrar e motivar o comportamento diário de seus filhos. Os recursos fornecidos pelo aplicativo incluem, entre outros:

  • Gerenciamento de perfis de crianças
  • Registro e acompanhamento de comportamentos
  • Sistema de pontos e mecanismo de recompensas
  • Gerenciamento de lista de desejos
  • Estatísticas e análise de dados
  • Sincronização de dados com o iCloud
  • Recursos de compartilhamento familiar
