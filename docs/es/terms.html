1. Descripción del Servicio

StarMint App es una aplicación para iOS orientada a padres, diseñada para ayudarles a registrar y motivar las conductas diarias de sus hijos. Las funciones que ofrece la aplicación incluyen, entre otras:

  • Gestión de perfiles de niños
  • Registro y seguimiento de conductas
  • Sistema de puntos y mecanismo de recompensas
  • Gestión de lista de deseos
  • Estadísticas y análisis de datos
  • Sincronización de datos con iCloud
  • Funciones de uso compartido en familia

2. Elegibilidad del Usuario

  • Debes tener al menos 13 años de edad para utilizar esta aplicación.
  • Si eres menor de 18 años, utiliza esta aplicación bajo la guía de un padre, madre o tutor.
  • StarMint App está diseñada para que padres o tutores gestionen y motiven el crecimiento de sus hijos.

3.2 Almacenamiento y Seguridad de los Datos

  • Tus datos se almacenan principalmente en tu dispositivo local.
  • Si activas la sincronización con iCloud, los datos se sincronizan con los servidores de iCloud de Apple.
  • No tenemos acceso a tus datos almacenados en iCloud.
  • Tú eres responsable de mantener la seguridad de tu dispositivo y de tu cuenta de iCloud.

3.3 Respaldo de Datos

Te recomendamos que realices respaldos de tus datos con regularidad. La aplicación ofrece una función de exportación en CSV que puedes utilizar para respaldar tus datos.
